# Proposed patterns

Patterns that are half-formed, unproven, or awaiting a real failure to
anchor them. They live here until they earn their way into the main
`patterns/` directory.

## What makes it in

A pattern moves from `proposed/` to `patterns/` when:

1. It has a real "When this bit me" story — not a hypothetical
2. The rule is stated as a one-liner that another agent could adopt
3. It has been applied more than once (one failure is a coincidence;
   two is a pattern)

## What's here now

Nothing yet. This directory is a placeholder for the pattern that
doesn't quite have enough evidence to graduate.

## Conventions

- Same structure as main patterns: rule, why it matters, when it bit me
- Filename matches the rule slug (kebab-case)
- No "should" without a counter-example
